# Agent rules — PlayStation 2

You are working in a single-HLE repository. Stay inside it.

- Read `docs/SOURCES.md` first. Only Tier 0/1 public documentation.
- No firmware, BIOS, ROM, key, leaked SDK, or disassembly. Ever.
- No GPL/non-commercial emulator code in a BSD-2-Clause module. Black-box
  oracle only, and record it.
- One task, one branch, one PR. Never push to `main`.
- Every behaviour gets a failing-first test; never edit a test to pass.
- The gate must pass on the exact PR head. "It worked earlier" is not evidence.
- State the claim level exactly: implemented / tested / boots / plays are four
  different claims.
- Write `handoff.md` with commands and exit codes.

The company board lives at https://github.com/0xJ1nn/ezcore-hle.
